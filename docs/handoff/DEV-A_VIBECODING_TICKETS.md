# AD Me DEV-A 바이브코딩 실행 티켓

이 문서의 43개 티켓, 총 219SP만 담당한다. 역할별 분업이 아니며 다른 담당도 UI·서버·DB를 모두 수정한다. 전체 88개 중 자기 담당을 넘어서 임의 재배분하지 않는다.

## 시작 프롬프트 — 코딩 에이전트에 그대로 전달

```text
너는 AD Me 프로젝트의 DEV-A 구현 담당이다. 이 문서와 같은 폴더의 SHARED_EXECUTION_CONTRACT.md를 모두 읽고 작업하라.
저장소의 기존 코드를 이어서 구현한다. AGENTS.md, 현재 git 상태, harness/service_backlog_v2.json, 세션 로그를 확인하라.
사용자는 외부 계정·콘솔·배포·API 키 발급/등록을 직접 한다. 너는 로컬 코드·마이그레이션·자동 테스트·브라우저 검증·사용자 적용 패키지를 완성하라.
준비된 자기 담당 P0부터 실행하며 선행 티켓이 미완료면 독립 가능한 코드/계약 테스트를 진행하라. 키가 없다고 모든 작업을 중단하지 마라.
가상 데이터를 실제 인플루언서로 위장하거나 mock 통과를 실제 공급자 검증으로 보고하지 마라.
티켓별 변경과 증빙을 저장하고 모든 수용 기준 통과 전 DONE으로 표시하지 마라. 사용자에게 터미널/코드 수정 작업을 떠넘기지 마라.
```

# 첨부 DEV-A 지시서 이행 검토 — 2026-11-20

검토 기준 `c450619` / 기존 `codex/dev-a-p0-continue`. 첨부 `김태권 이번주.md`은 저장소 DEV-A 지시서와 동일한 43티켓·219SP 문서다. SHA256 `bec49fe65596188a9f9dce624808f2d095d571178f06dd4a942bc6ff442daede`. 첨부 폴더의 공유 계약 파일은 없어서 저장소 계약을 읽었다.

문서는 구현 지시이고 완료 증거가 아니다. 현재 사용자 요청은 지시서와 작업을 대조하고 남은 구현을 진행하는 것이다. 외부 계정/콘솔/키/배포는 기존 사용자 범위를 유지하며 문서만으로 별도 외부 작업을 승인받았다고 해석하지 않는다. 기존 브랜치 사용 지시는 계속 따른다.

검토 결론: 담당 범위·기존 코드 유지·티켓 커밋·로컬/실제 제공자 구분·상태 원장 방식은 대체로 따랐다. 다만 전체 문서를 구현한 상태는 아니다. 착수 전 기준 LOCAL_VERIFIED5, IN_PROGRESS11, PARTIAL_VERIFIED1, BLOCKED_EXTERNAL2, OPEN24, DONE0이다. LOCAL_VERIFIED도 최종 적용·리뷰 통과를 뜻하지 않는다.

이번 검토는43개 기준/선행/커밋/증거 경로를 대조하고 핵심 코드 경로를 확인했다. 과거 증거가 존재한다는 것과 현재 모든 수용 기준이 통과한다는 것은 다르다. 외부 제공자·배포·법률 검토를 새로 수행한 전수 기능 검증이 아니다. 상세 원문 기준·부정 조건·커밋·파일 존재 여부는 [기계 판독 검토](../../harness/evidence/DEV-A-DOCUMENT-AUDIT-20261120/review.json)에 보존했다.

## 확인한 누락과 처리

- **D034**: 단일 선택만 있고 URL·reload/back/forward 복원이 없다. 본인 등록의 미확보 followers0을 숫자로 필터링하며 정렬 tie-break도 없다. 이번에 독립 가능한 다중 필터/URL/0·결측/오류/경합 계약을 구현하고 실제 브라우저로 검증한다. D033 서버 검색은 별도 미완료다.
- **D018/D075/D033**: publicCreators가 owner_id와 raw profile 전체를 client props로 전달한다. 공개 DTO allowlist와 nullable 지표로 앱 경계를 보수한다. **기존 직접 REST의 공개 creators 행/owner_id 권한과 user-<Auth UUID> 공개 주소는 별도 출시 차단**이며 앱 projection만으로 고쳤다고 보고하지 않는다. D033 읽기 경로·opaque-ID/alias와 제안 권한 계약을 함께 이관해야 한다.
- **D051**: RLS·메시지 한도는 있지만 idempotency·cursor 페이지네이션·안전한 첨부·신고 UX는 미완료다. 원장 blocker의 “RLS만” 표현은 quota 증거까지 포함하도록 명확히 하되 완료로 승격하지 않는다.
- **D073/D080/D014**: 정적 정책 안내/프로필 숨김은 동의 버전·성인 범위 확인·Auth/Storage/파생 데이터 완전 삭제가 아니다. U001 정책 승인과 D079 보존/철회 계약을 발명하지 않는다.

# DEV-A 선행사항과 이번 구현 범위

후속 독립 구현(같은 날): 아래 미착수10개는 이제 IN_PROGRESS이며 실제 화면/API5개와 계약 코어5개를 추가했다. 선행 조건과 전체 수용 기준은 그대로다. 상세 구현/남은 부분/실제 대 fixture 검증은 [독립 구현 증빙](../../harness/evidence/DEV-A-INDEPENDENT-20261122/README.md), 새 단일 SQL 적용은 [67→68 패킷](../../deliverables/dev-a-independent-20261122/README.md)을 따른다. 아래 원래 네 티켓 배치와 보류 표는 당시 범위의 이력이며 후속 상태는 runtime-status.json이 기준이다.

2026-11-22, 기존 codex/dev-a-p0-continue. 원본 배분은 DEV-A43개이며 다른 담당 티켓은 재배분하지 않는다. LOCAL_VERIFIED는 로컬 코드/검증 상태다. 실제 적용·교차 리뷰·출시 DONE과 구분한다.

이번에 독립 구현: **D030 광고 이력 검색/개인 경쟁사, D031 출처별 관측 그래프, D035 승인 지표 가용성 필터, D060 업무별 운영 검색/감사**. 기존 D029/D021/D075/D059 로컬 계약을 사용하며 D035는 새 D031 뒤에 진행한다. 실제 SNS 자료/권리를 대신 생성하지 않고 승인 전 자료는 비공개다.

위 결과가 없다고 로컬 구현 가능한 네 티켓을 멈추지 않는다. 새 시계열 공개는 현재값 공개와 별도 defaultOFF다. 실제 공급원별 공개 허용 이력·최대 기간·권리 근거가 들어오면 개발자가 검토된 활성화 패킷을 준비한다. 로컬 구현 완료와 이 공통 출시 승인을 구분한다. 정책/플랫폼 승인이나 실제 공급자 성공을 가상 fixture로 대체하지 않는다. USER 작업은 외부 사실 확정·콘솔 적용·배포 조율이며 터미널/코드 편집/패키지 설치를 요구하지 않는다. 최종 전달 패킷과 개발자 검증 증거는 이번 배치 종료 시 함께 연결한다.

# 2명·14일 실현 일정

**P0 전부는 도전적인 범위**다. 단계별 골든패스를 먼저 완성하고 나머지 P0의 범위를 평가해 기능을 축소한다. 하네스는 기능이 미완성인 상태를 정확히 보고해야 한다.

| 날짜 | 엔지니어 A (UI/UX + client) | 엔지니어 B (DB/backend/matching) | 공동 검사 |
|---|---|---|---|
| D1 | UI 레퍼런스/디자인 토큰/로고 | 프로젝트 생성/TS/툴/Repo | 요구사항 및 스키마 확정 |
| D2 | 공통 레이아웃·로그인 UI | Supabase·Auth·RLS | 역할 분리 확인 |
| D3 | 랜딩/탐색 화면 | seed 및 creators query | 페이지 연결 |
| D4 | 필터·프로필 상세 | 크리에이터 CRUD, 원본 링크 | 검색/데이터 검사 |
| D5 | 캠페인 양식 | 캠페인 DB/API | 신규 캠페인 저장 |
| D6 | 매칭 결과/점수 상세 | 순수 TS matcher + 단위테스트 | 유사성/결측 검증 |
| D7 | shortlist·비교 UI | 후보선정/추천 저장 | 브랜드 골든패스 중간 점검 |
| D8 | 모집/지원자/제안 UI | applications/proposals 상태 머신 | 양면 로그인 E2E |
| D9 | 크리에이터 대시보드 | 메시지/알림/결과물 | 상태 동기화 |
| D10 | 가격/결제 UI | Toss 테스트 주문/서버 승인 | 테스트 카드·실패 시나리오 |
| D11 | HOT 광고 표시/청구내역 | entitlement/권한 검증/중복 방지 | 테스트 결제 E2E |
| D12 | 이슈/광고이력/관리자 UX | 출처 관리/신고/관리자 검사 | 보안 회귀 |
| D13 | 모바일, 접근성, 비주얼 마감 | 성능·RLS·CI·테스트 | 전 루트 통합 QA |
| D14 | 3분 시연, 사업계획 UI | 빌드/배포 매뉴얼/데이터 복원 | 새 브라우저 시연 리허설 |

**시간 부족 시 축소:** (a) 실시간 채팅 -> 메시지 게시판, (b) 일괄 CSV -> 수동 등록, (c) 고급 지표 -> 출처가 있는 정보만, (d) 자동 뉴스 검색 -> 운영자 검토 기록, (e) 자동 청구 -> 30일 테스트 이용권.

# 사용자·운영자·외부 승인

U001–U020은 이전 ID를 유지했다. BUSINESS U021–U022는 유료 판매 결정에만 적용한다. 현재 방침은 사업자등록 미추진이다. 개발자는 격리 환경·변경 패킷·검증 보고를 준비한다.

| ID | 필요한 조치 | 완료 확인 |
|---|---|---|
| U001 | 운영 주체·연락·처리 근거·기간·위탁·권리 행사 승인 | 정책 버전·시행일·문의 처리 검증 |
| U002 | GitHub 역할과 Vercel 연동 정책 승인 | 앱 접근 범위와 자동/수동 배포 모드 확인 |
| U003 | 실제/시연/격리 DB 소유권, 리전·한도·보관 확인 | 프로젝트 구분과 보존·복구 선택 기록 |
| U004 | 검토된 SQL/RLS/Storage/함수 패킷 승인·적용 | 복원 실험, 원격 migration ledger, 앱/RPC 검증 |
| U005 | Vercel 프로젝트·도메인·승격과 복구 운영 | 버전·도메인·롤백 기록 |
| U006 | 공급자 키를 각 환경에 등록·회전 | 값 없는 키 이름/환경/scope/회전 이력 |
| U007 | SMTP·발신 도메인 및 신규 수신 확인 | 실제 수신과 SPF/DKIM/DMARC를 확인하며 메일 원문은 비공개 |
| U008 | Auth redirect·템플릿·세션·MFA 설정 승인 | 콜백 허용/거부·복구·MFA 검증 |
| U009 | 공식 YouTube API 프로젝트 제한·쿼터·키 설정 | 제한 범위·유지보수 주체와 원본 호출 확인 |
| U010 | 파생 지표·AI 분석 목적과 정책 수락/심사 검토 | 데이터 필드별 허용 증빙과 제한 목록 |
| U011 | 공식 API 외 소재의 소스·라이선스·처리 근거 확인 | 허용 대상·필드·철회 증빙. 없으면 비활성 |
| U012/U013 | Instagram/TikTok은 현재 범위 밖 | 역사 기록을 유지하고 새 연동은 열지 않음 |
| U014 | 실제 창작자·브랜드 QA에 참여와 권리·철회 범위를 요청 | 적법한 자료·소유권·협업 증거 |
| U015 | 격리 Toss TEST 상점 세트 확인·등록 | TEST 상점과 SDK v2 상태 확인. 키 자체 미공유 |
| U016 | 외부 LLM은 선택. 필요해질 때 자료 처리·비용·보존 승인 | 외부 승인 문서 또는 Local AI 유지 결정 |
| U017 | 도메인·TLS 운영 유지 | apex 200, www 308, canonical 확인. 현재 검증됨 |
| U018 | 외부 백업, 채널 경보, 접근 권한·당직 지정 | 복원 시험, 저장 키 보관 책임, 알림 수신 증빙 |
| U019 | 실제 이메일·소유권·MFA와 TEST 결제 참여 | 환경별 성공/실패 결과를 비밀값 없이 기록 |
| U020 | 무료/유료 출시 결정을 분리, 사고 대응 책임 확인 | 최신 [판정](GO_NO_GO.md)과 담당 승인 |
| U021 | 정식 판매 추진 여부 및 사업 주체·고지·환불 검토 | 정식 승인 또는 미추진 결정 |
| U022 | U021 후 Toss 계약·심사, 운영 상점 및 비공개 키 등록 | 상점·결제수단·운영 환경 승인 및 대사 책임 |

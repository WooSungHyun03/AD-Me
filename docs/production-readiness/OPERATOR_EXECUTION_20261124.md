## 디자인과 기능 검증 범위

- 피처링의 검색·자동 후보 목록 화면에서 검색 진입점과 리스트의 위계를 관찰했다. REVU 사업 사이트와 소개 사이트에서는 광고주 CTA와 서비스 안내를 확인했다. AD Me 홈에는 실제 공개 채널 프리뷰와 기존 추천 입력, 브랜드와 크리에이터별 실동작 링크를 배치했다. [피처링 검색](https://featuring.co/product-search) · [REVU 기업 소개](https://corp.revu.net/) · [REVU 광고주](https://biz.revu.net/)
- 흰색·밝은 회녹색의 공통 표면과 라임 CTA를 적용했다. 홈 장식은 탭이 숨겨지거나 화면 밖으로 나가면 멈추며, 정지 버튼 및 `prefers-reduced-motion`을 지원한다.
- YouTube 공개 정책의 허용 여부는 수치·데이터 처리별로 판단한다. 운영 정책 승인 증빙과 데이터 보존/삭제 범위는 U010·U011에서 확인한다. [YouTube API Services 개발자 정책](https://developers.google.com/youtube/terms/developer-policies)

## 실행 증빙

- 앱 코드 SHA `2f5d1d14358e26ce66c21f4bd248d6c29ec06974`. lint, TypeScript 검사, Next.js 빌드, Vitest 506건, Python 43건 통과.
- Vercel 최초 실패 두 건을 확인했다. 프리뷰 격리 URL의 형식을 수정했고, `.vercelignore`의 `deliverables` 패턴을 루트에 고정해 결과물 API가 클라우드 빌드에 포함되게 했다. 최종 디자인 프리뷰는 Vercel 로그인 보호 상태다. [AD Me 프리뷰](https://ad-dginyfh7j-sunghyuns-projects-da008879.vercel.app)
- 7개 폭에서 홈·검색·요금제의 밝은 표면, 가로 넘침, 자동 모션 일시정지·감소 모션, 공고 게시권 CTA, YouTube 필터를 재실행했다. 대상 10건 통과. axe가 지적한 비교/검색 체크박스를 24px로 키운 뒤 홈·탐색·요금제 6화면에서 해당 위반 0건. 격리 브라우저 전체 점검은 50개 화면 템플릿, 54개 역할별 진입, 180개 화면 점검 기록이다. 관리자 검토 화면 1건은 리디렉션 도중 캡처가 실패했다.
- 넓은 초기 회귀 30건에서 10건 통과 및 20건 실패를 기록했다. 주제 필터 2건은 가상 채널에도 주제 메타데이터를 넣어 재검증을 통과했다. 나머지 실패에는 SMTP/Toss 테스트 환경 설정 및 이전 캠페인·대시보드·권한 테스트의 계약 차이가 포함된다. 개별 범위 확인 결과로 전체 회귀를 완료 처리하지 않는다.
- 로컬 상품 분석 보안 검사 9건 통과. 영속 DB에서 타인 권한 거부, 중복 작업·할당량 차감 방어, 변경한 입력과 삭제한 상품의 결과 차단을 확인했다. 상태 점검 API의 관리자 진단은 최근 OTP 검증을 요구하도록 수정했다.
- Lighthouse 로컬 개발 서버 진단은 접근성 100, 성능 97, LCP 약 915ms, CLS 0.0023, TBT 204ms다. 운영 현장 INP는 별도 계측이 필요하다.
- 보안 스캔에는 설정 파일과 등록된 키 패턴 검사 범위를 적용했다. 운영 백업·복원, 실제 Toss 승인, 운영 계정의 새 인증·동의, D088 전체 운영 시나리오를 검증할 증빙이 남아 있다.

- 보호된 프리뷰의 홈·탐색·요금제·공고는 인증된 요청에서 HTTP 200을 반환했다. 브라우저에서 홈·탐색·요금제를 390px와 1440px로 열어 확인했다. Vercel 프리뷰는 공개 서비스 DB와 분리한 화면 확인용이다.
- 격리 브라우저에서 익명과 OTP 인증 전 관리자가 공개 상태만 받는지 확인했으며, 실제 TOTP 인증 후에 진단을 조회했다.
- Local AI 합성 상품 설명은 근거를 포함한 제안 2건을 생성했다. 합성 문구에서 추출한 콘텐츠 태그 3건은 검토 대기로 반환됐다.
- D087 격리 복구 훈련은 SQL 복원 뒤 비공개 Storage 파일 재업로드에서 `42P10` 오류로 실패했다. 운영 데이터와 운영 키를 사용하지 않았으며, Storage 메타데이터와 파일 바이트가 함께 복원될 때까지 U004의 운영 적용을 보류한다.

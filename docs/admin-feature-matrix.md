# 운영 콘솔 권한

운영 콘솔은 /admin/intelligence에서 열 수 있다. 기존 /admin의 신고·프로필·이용권·결제 관리는 계속 사용할 수 있다.

|역할|새 화면과 권한|
|---|---|
|Super Admin|운영 역할 부여, 일일 수집 설정, 전체 운영 데이터|
|Content / Data Manager|YouTube 채널 작업 등록, 내부 승인·반려, 수집·AI 작업 상태 조회|
|Campaign Manager|최근 캠페인과 상태 조회|
|Finance Manager|최근 TEST 주문과 상태 조회|
|Support Manager|최근 회원과 유형 조회|

기존 admin 계정은 Super Admin으로 매핑된다. 운영 역할은 일반 회원가입이나 회원 프로필 수정으로 취득할 수 없다. DB가 운영 변경 권한을 다시 검사하고 변경을 기존 감사 로그에 남긴다. 운영 작업 표에는 일반 사용자의 AI 프롬프트와 생성 결과를 포함하지 않는다.

회원 정지·복구, 탈퇴 처리, 상세 통계 차트, 고급 데이터 테이블, 캠페인 상태 편집, 환불·이용권 조정, 소유권 분쟁 처리 및 광고 검토 작업 흐름은 추가 구현이 필요하다.

새 운영 콘솔 접근과 역할별 DB 권한을 확인했다. 기존 등록된 관리자 계정으로 검증했다. 일반 이메일 확인만으로 운영 권한을 부여하지 않는다.

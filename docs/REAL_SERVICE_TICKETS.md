이번 문서는 실제 운영을 위한 **남은 작업**이다. 기존 코드를 초기화하지 않는다. 모든 개발 티켓은 OPEN이며 완료 선언이 아니다. 기존 40개 Harness 작업과 실행 증거는 유지한다. 개발 A/B는 사람이 맡을 작업 묶음이며 직군 구분이 아니다.

## 1. 운영 범위와 우선순위

- 기본 출시: **무료, 성인 대상, 실제 출처가 확인된 크리에이터 탐색·캠페인·추천·협업 베타**. 사업자등록을 가입 필수로 요구하지 않는다. 운영자 신원·연락처·개인정보 처리 책임은 별도 확정한다.
- 실제 유료 상품 판매·수수료 수납·정산·자동결제는 현재 제외한다. TEST 상품은 격리된 시연 환경에서만 검증한다. 무료 운영이 개인정보·저작권·플랫폼 약관 의무의 면제를 뜻하지 않는다.
- P0 = 무료 실제 데이터 베타의 출시 필수. P1 = 출시 후 가치 확장 및 선택적 TEST 결제. P2 = 승인·평가 후 확장. Instagram/TikTok 승인이 YouTube 기반 베타 전체를 막지 않도록 한다.
- 배포 사이트 설정·실제 배포/롤백·외부 콘솔 변경·API 키 발급/등록/교체는 **사용자만 수행**한다. 개발자는 코드·마이그레이션·테스트·설정명 목록·안내를 준비한다. 사용자를 수동 코딩 담당자로 배정하지 않는다.
- U 티켓에 이미 준비된 계정·설정은 사용자 확인으로 충족 처리할 수 있다. 다시 만들라는 의미가 아니다.

|본인 등록|자기 SNS·견적·포트폴리오 및 협업 수신 동의|소유 증명·권리 확인·삭제/철회. 동의는 플랫폼 약관까지 대체하지 않음|

미청구 공개 프로필은 “협업 가능”으로 간주하지 않는다. 개인 이메일/전화 수집·무단 대량 제안은 제외한다. 광고 이력은 근거가 있는 기록만 사용하고 인구통계·견적·가짜 팔로워·이슈를 임의 생성하지 않는다. 공급원마다 원본 지표와 AD Me 계산 결과를 구분한다.

- [Meta의 무허가 스크래핑 관련 공식 설명](https://about.fb.com/news/2021/04/how-we-combat-scraping/) 및 [Instagram 비즈니스 계정 공식 문서](https://developers.facebook.com/docs/business-management-apis/business-asset-management/guides/instagram-accounts): 자동 수집 허용과 계정/API 범위를 따로 확인한다. 로그인 제한으로 전체 최신 약관을 확인하지 못한 경우 U011/U012에서 사용자 확인을 남긴다.
- [TikTok Display API](https://developers.tiktok.com/docs/en/display-api-overview), [Research API FAQ](https://developers.tiktok.com/docs/en/research-api-faq/): 동의 기반 연결과 연구용 접근 자격을 구분한다.
- [개인정보보호위원회 공개 개인정보 처리 안내](https://pipc.go.kr/np/cop/bbs/selectBoardArticle.do?bbsId=BS217&mCode=D010030000&nttId=10425): 공개되어 있는 개인정보도 이용 목적·근거·권리 보호 검토가 필요하다. 이 AI 안내를 AD Me의 수집 법적 근거로 자동 적용하지 않는다.

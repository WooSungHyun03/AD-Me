# 발표 시연 운영계획 — 가상 데이터

## 사전 준비
- 동일한 데이터셋에서 브랜드 사용자/크리에이터 사용자/관리자 사용자를 준비한다. 계정 이메일·암호는 저장소에 넣지 않는다.
- 48 synthetic creators / 8 synthetic campaigns와 광고 이력 샘플은 DEMO임을 보여준다.
- 데모 실행 하루 전 DB backup 또는 seed reset 방법 확인.
- Toss 테스트 키 셋업, 실패/성공 모두 확인. 네트워크 장애용 실제 결제 영상은 '녹화 백업'임을 표시.

## 3분 골든패스
1. [00:00-00:25] 문제 제기: 탐색/비교/제안 분절 → AD Me 통합.
2. [00:25-00:55] 브랜드가 비건 토너 캠페인 생성(청아함/자연스러움/쇼츠/예산).
3. [00:55-01:25] AI 추천 Top 3 + 점수·누락된 지표 표시.
4. [01:25-01:50] 프로필/검증된 광고 이력/중립적 검토자료 확인.
5. [01:50-02:20] 브랜드가 제안 전송 → 크리에이터 계정에서 수락 → DB 반영 확인.
6. [02:20-02:45] HOT 및 Pro 상품·Toss 테스트 결제 흐름/권한 갱신.
7. [02:45-03:00] B2B 구독 / HOT / 8% 수수료 계산 + 향후 확장.

## BM
- Brand Pro 49,000원/30일, Agency 149,000원/30일, HOT 9,900원/30일, AI credit optional.
- 수수료 8%는 실거래 시뮬레이션. 실제 매출, ROI, 예상 고객 수를 실적처럼 제시하지 않는다.

## 발표 실패 대비
- 네트워크 불안정이면 이미 저장된 DB 기반 추천을 재실행한다.
- 외부 LLM 없으면 deterministic 추천이 동작한다.
- 결제 SDK 실패 시 완료로 가장하지 않고 테스트 조건/장애를 설명한다.

# AD Me — 기능 명세서 (Product Requirements)

## 목적·페르소나
- 광고주/브랜드: 브랜드 이미지를 정의하고, 조건에 맞는 크리에이터를 검색·검증·제안하고 진행 상황을 추적한다.
- 인플루언서/크리에이터: 자신의 SNS·포트폴리오·이미지·광고 가능 카테고리를 관리하고 캠페인에 지원하거나 제안을 수락한다.
- 운영자: 데이터 출처·신고·이슈 검토·승인·프로모션·테스트 거래를 관리한다.

## P0 / P1 / P2 정의
- **P0**: 2인 14일 핵심 제품 완성의 필수 범위. 실제 DB 상태 및 자동 테스트 필요.
- **P1**: P0 통과 후 구현 가능한 사용자 가치가 큰 확장. 구현 못하면 정확히 미구현 표시.
- **P2**: 상용급 확장/외부 계약·심사·데이터 라이선스 의존성. 설계 문서와 backlog로 유지, 2주 완료를 요구하지 않음.

## 수익 모델
- Brand Free: 0원, 기능/월 사용 제한
- Brand Pro: 49,000원/30일 (테스트 결제 이용권)
- Agency: 149,000원/30일 (테스트 결제 이용권, 실제 팀 기능은 P1)
- Creator HOT: 9,900원/30일 (광고로 명시된 별도 노출)
- AI Credits: 예시 30크레딧 9,900원 (테스트 구매, 실제 AI 비용은 API 설정 필요)
- 매칭 수수료: 거래액의 8%를 계산만 함. 실제 거래·정산 불가.
- 가격은 검증된 시장가격이 아닌 제품 가설, 관리자 설정 가능.

## 불변 규칙
- 추천 순위는 광고비를 지불했다는 이유로 조작하지 않는다.
- 미확인 데이터는 기본값 0점 또는 임의 값으로 덮지 말고 결측 처리.
- 개인정보·초상권·API 약관 위반을 2주/비상업 핑계로 무시하지 않는다.
- 실제 연동/외부 API 미구현을 '지원'이라고 표현하지 않는다.

# Figma 기준 시각 검증

## 이번 적용

- 홈 및 헤더를 `11:91`, `11:1402`, 메뉴를 `25:1099`의 design context와 참조 렌더에 맞췄다.
- 캠페인 목록 `25:809`, `25:840`과 상세·작성 `25:870`, `25:921`을 기존 `/jobs` 경로에 적용했다. 테이블·RPC·저장된 URL은 유지한다.
- Figma 내려받기 소스의 로고, 홈 히어로 사진, 두 에디토리얼 사진의 해시를 자산 원장에 남겼다. 실제 크리에이터·캠페인 대신 시안의 사진과 통계를 배치하지 않는다.
- 1440px와 390px에서 Figma와 로컬 렌더를 비교했다. 캠페인 데이터에 이미지·모집 인원 필드가 없으므로 칩과 카드에 반환된 항목만 보인다. 무료 공개 환경은 체험 가격과 결제 버튼을 숨긴다.
- 이전 UI의 추천 입력, 모바일 내비게이션, 공고 DB 소유권 경계, 감소 모션과 정지 동작의 회귀를 격리에서 확인한다.

실제 운영의 변경 확인은 스키마·복구 검증 뒤 실시한다. 전체 Figma 프레임의 고충실도 적용 및 3회 전사 화면 검수는 계속 진행 중이다.

- 로그인·회원가입은 `11:361`, `11:1537`, `11:379`, `11:1546`의 데스크톱·모바일 구성을 적용했다. 기존 이메일/정책 게이트를 보존하며 Figma 시안의 Google 또는 시연 계정 진입은 제품에 추가하지 않았다.
- [프로토타입 인벤토리](figma-prototype-inventory.json)는 원본 프레임별 이미지 슬롯 참조 수, 연결된 노드 대상, 17개 변수의 값을 담는다.

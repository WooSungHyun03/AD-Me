# Figma 적용 및 추가 설계 상태

원본 Page 1에서 디자인 시스템 1개와 사용자 화면·변형 48개를 읽었다. 캠페인 명칭과 내비게이션을 갱신한 편집 가능 복제본 13개는 별도 Figma 페이지에 있다. [원본 AD ME](https://www.figma.com/design/1JgK1dH2xyFKU4ED0GIXz9/AD-ME?node-id=0-1) · [Production Extensions](https://www.figma.com/design/1JgK1dH2xyFKU4ED0GIXz9/AD-ME?node-id=25-808)

| 화면·기능 | 상태 |
| --- | --- |
| 홈, 전역 내비게이션, 캠페인 목록 | 웹 구현 및 격리 브라우저 검증 진행 |
| 캠페인 상세·작성 및 지원 진입 | 기존 RPC·Server Action을 사용한 기본 화면 구현. Figma에 있는 공개 이미지, 제안 단가·제작 가능일 등 추가 필드는 데이터 계약 작업이 필요하다. |
| 인증 콜백·메일 재발송·비밀번호 복구, MFA, 정책, 계정 설정, 접근 거부 | 기존 화면이 있으며 필요한 Figma 확장 설계를 별도로 작성해야 한다. |
| 공급자 실패·취소, 승인된 실결제, 채팅 신고·차단, 프라이버시 운영 하위 화면 | 기존 계약과 Figma 설계 사이의 공백을 먼저 확인한다. |
| 시안의 예시 채널·점수·캠페인 사진 및 단가 범위 | 공개 페이지에는 출처가 있는 실제 채널·캠페인 DTO를 표시한다. 별도 이미지나 추가 지표가 없는 캠페인은 현재 데이터만 표시한다. |
| Desktop/Mobile prototype 재연결 | 원본 반응과 대상은 유지했다. 추가 페이지 내 복제본끼리의 전체 전이 재검증이 남았다. |

개별 원본·확장 ID와 실제 경로는 [프레임 목록](figma-frame-map.json)에 있다.

# U014 — 실제 크리에이터 시범 참여·운영 동의

담당: 사용자 · 우선순위: P0 · 현재 상태: BLOCKED_PARTICIPATION · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

파일럿 참여자·권리 증명·협업 수신 동의·소유권 분쟁 연락 창구를 확보한다. 무단 제안 메일 대량 발송은 하지 않는다.

## 시작 전에 개발자가 준비할 것

D024/D025/D029의 파일럿 양식·소유권 증명·프로필 청구·협업 수신 동의·정정/삭제 처리 화면.

## 사용자가 수행할 순서

1. 시범 참가자의 모집 경로와 범위를 정한다. 공개 이메일 수집 후 무단 대량 제안을 보내지 않는다.
2. 참가자가 직접 동의한 플랫폼 연결/소유 증명을 수행하고 프로필 공개·협업 제안 수신 여부를 각각 선택하게 한다.
3. 포트폴리오/사진·광고 이력 자료는 본인 제출 권한과 출처를 확인하고 확인되지 않은 항목은 미확인으로 둔다.
4. 일부 실제 공개 미청구 프로필과 동의 참가자의 표시·제안 가능 여부가 구분되는지 확인한다. 파일럿 목표 50~100개와 실제 확보 수량을 구분한다.
5. 권리 요청·동의 철회·소유권 분쟁 연락 경로를 참가자에게 안내하고 삭제 후 재수집 방지 샘플을 검증한다.

## 검증·개발자 인계

집계된 참여 수·동의/청구 완료 수·출처 충실도·삭제 검증. 참가자 명단/연락처/증명 원본은 공개하지 않는다.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

참가자/확보 데이터가 부족하면 수량과 미검증 범위를 그대로 기록하고 가상 계정을 실제 참가자로 채우지 않는다.

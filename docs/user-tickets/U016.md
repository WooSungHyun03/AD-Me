# U016 — 선택적 LLM 계정·키·비용 상한

담당: 사용자 · 우선순위: P1 · 현재 상태: OPTIONAL_NOT_ENABLED · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

키·처리 조건·국외이전 해당 여부·예산 한도를 직접 설정한다. 미설정 시 fallback으로 운영한다.

## 시작 전에 개발자가 준비할 것

D048의 provider adapter·서버 변수명·모델/endpoint·최소 데이터·usage 상한·fallback·오류 처리 구현.

## 사용자가 수행할 순서

1. 필수 기능은 키 없이 동작함을 확인하고 LLM 연결이 실제로 필요한지 결정한다. 필요 없으면 OPTIONAL_NOT_ENABLED로 사유를 남긴다.
2. 연결할 공급자/모델의 이용 조건·입력/출력 보존·학습 사용·지역/국외이전·사업 목적 적합성을 확인한다. 무료 크레딧이 영구 무료라는 의미는 아니다.
3. 최소 권한 프로젝트 키를 발급하고 월/일 예산·요청 제한·모델 한도를 설정한다. 하드 비용 상한이 없는 공급자는 앱 수준 차단도 요구한다.
4. D003가 확정한 서버 비밀 변수로 등록하고 재배포한다. 클라이언트 변수로 모델 키를 전달하지 않는다.
5. 민감 메시지/사적 메모를 넣지 않은 샘플로 응답·fallback·한도 초과·타임아웃을 확인한다. 외부 자동 전송은 하지 않는다.

## 검증·개발자 인계

공급자/모델·설정 환경·비용 상한·처리 조건 검토·샘플/fallback 결과. API 키 제외.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

요금/약관이 맞지 않거나 키가 없으면 deterministic fallback으로 유지한다. 결제 강제 연결은 하지 않는다.

# U001 — 서비스 운영 범위·정책·운영자 확정

담당: 사용자 · 우선순위: P0 · 현재 상태: PARTIAL_VERIFIED · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

무료 성인 베타·수집 목적·권리 행사 연락처·처리 기한·정책 문구를 확정한다. 필요하면 전문 검토를 받는다.

## 시작 전에 개발자가 준비할 것

D017/D064/D073/D080의 데이터 흐름·정책 초안·실제 수집 항목·권리 요청 처리안. 초안에는 미확정 부분을 표시한다.

## 사용자가 수행할 순서

1. 운영 범위를 무료 성인 베타·지원 플랫폼·서비스 제공 범위로 확정한다. 미수집 데이터/미제공 기능을 약속하지 않는다.
2. 운영자 이름 또는 공개 명칭·실제 연락 가능한 지원/권리 행사 주소·운영 시간을 정한다. 개인 집 주소 등 불필요한 정보를 공개하지 않는다.
3. 공개 프로필 수집 목적·필드·이용 근거·이미지/콘텐츠 권리·보존/삭제와 Supabase/메일/LLM 처리위탁·국외이전 해당 사항을 검토한다.
4. 개인정보 처리방침/이용약관/선택 동의를 읽고 확정 버전·시행일·검토자를 기록한다. 애매한 법적 근거는 전문 검토 전 수집 허용으로 표시하지 않는다.
5. 신고/정정/삭제 처리 책임자와 내부 목표 시간을 정한다. 법정 의무 기한은 적용 상황·최신 규정에 따라 별도 확인한다.

## 검증·개발자 인계

정책 버전·시행일·운영 연락처 확인·승인한 데이터 공급원·미확정 쟁점 목록. 비공개 검토 의견은 공개 저장소에 올리지 않는다.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

근거/운영 연락처/삭제 절차가 확정되지 않으면 해당 수집과 공개를 중단한다. 무료라는 이유로 생략하지 않는다.

# U010 — YouTube 이용 정책·파생 지표 승인

담당: 사용자 · 우선순위: P0 · 현재 상태: BLOCKED_USER_DECISION · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

유스케이스·보관/갱신·파생 지표 요건을 확인하고 필요한 정책 개정 수락·심사·쿼터 신청을 수행한다.

## 시작 전에 개발자가 준비할 것

D017/D031/D044/D047의 원본/파생 지표 목록·표시 문구·보존/갱신·삭제 정책·실제 용도 설명.

## 사용자가 수행할 순서

1. YouTube 개발자 정책과 추가 파생 지표 정책을 현재 버전으로 확인하고 확인일·URL·적용 범위를 기록한다.
2. 원본 채널 지표 표시와 AD Me 추천/분석 지표가 어떤 API 데이터를 쓰는지 개발자 목록을 검토한다. 조건이 다른 지표를 하나의 승인으로 묶지 않는다.
3. 필요한 정책 개정 수락/분석 용도 신청/감사를 공식 경로로 진행한다. 접수와 승인·약관 수락을 구분해 결과를 기록한다.
4. 개정 수락·요건 충족이 확인되지 않은 파생 지표는 비활성 상태로 둔다. 독자 계산 결과를 YouTube 공식 점수/인증으로 표시하지 않는다.
5. 보관/갱신·삭제·독립 분석 표시·쿼터 확대 필요를 D017 정책 registry와 대조하고 변경 시 재검토 일정을 정한다.

## 검증·개발자 인계

정책 버전·검토/수락/승인 상태·허용 지표·미허용 기능·신청 참조번호(민감값 제외).

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

거절/미확인은 원본 허용 데이터와 자체 입력 정보 중심으로 베타 범위를 축소한다. 분석 점수를 이름만 바꿔 우회하지 않는다.

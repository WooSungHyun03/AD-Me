# U011 — 웹 수집 대상의 허용 근거 확보

담당: 사용자 · 우선순위: P1 · 현재 상태: USER_ACTION_REQUIRED · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

대상 도메인 약관·라이선스·필요한 허가와 개인 정보 처리 근거를 확인하고 허용 목록을 승인한다.

## 시작 전에 개발자가 준비할 것

D017/D020의 정확한 도메인·경로·필드·빈도·이용 목적·권리 근거·robots 및 약관 검토표.

## 사용자가 수행할 순서

1. 대상 도메인의 현재 이용약관·자동 수집 정책·robots·콘텐츠 이용 조건을 검토한다. robots 허용은 별도 이용 허락과 구분한다.
2. 공개 전문 프로필의 개인정보 처리 근거·목적 적합성·최소 수집·권리 행사 경로를 확인한다. 허용 여부가 모호하면 권리자 허가나 검토를 확보한다.
3. 필요한 허가는 사용자가 직접 확보하고 출처·범위·기간·연락 창구·재배포/이미지 조건을 비공개로 보관한다. 수집 대상에게 연락하는 것도 사용자가 판단·수행한다.
4. 승인된 domain/path/field/rate/expiry만 allowlist로 개발자에게 전달한다. 로그인 벽·CAPTCHA·IP차단 우회·사적 연락처는 허용하지 않는다.
5. 허용 표본 수집과 삭제 요청 반영을 검증하고 약관/허가 변경 시 해당 공급원을 중단하도록 운영한다.

## 검증·개발자 인계

허용 목록·필드·허가/검토 참조·만료일·속도 상한·삭제 연락 경로. 허가 원문에 개인정보가 있으면 공개하지 않는다.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

허가/근거가 없으면 해당 도메인은 비활성으로 둔다. 전 SNS 크롤링을 구현 가능하다고 약속하지 않는다.

# U017 — 도메인·DNS·TLS·소유권

담당: 사용자 · 우선순위: P1 · 현재 상태: VERIFIED_CUSTOM_DOMAIN · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

필요 시 도메인 소유권·DNS·서비스 주소를 설정한다. 도메인 구매는 선택 사항이며 무료 URL로 시작할 수 있다.

## 시작 전에 개발자가 준비할 것

D083/D085의 최종 canonical origin·DNS 설정 요구·Auth callback/메일 도메인 영향 목록.

## 사용자가 수행할 순서

1. 무료 vercel.app 주소 유지 여부부터 정한다. 도메인 구매는 필수로 가정하지 않는다. SMTP 공급자의 별도 발신 도메인 요건은 U007과 분리 판단한다.
2. 커스텀 도메인을 쓰면 사용자 소유 DNS 계정에서 대상 Vercel 프로젝트에 도메인을 추가한다. 현재 Dashboard가 제시한 DNS 값을 사용한다.
3. 기존 MX/TXT/메일 인증 레코드를 보존하고 웹 연결에 필요한 레코드만 변경한다. 값은 문서의 오래된 IP로 고정하지 않는다.
4. TLS 발급/도메인 소유권 검증 후 www/apex 정책과 한 canonical origin을 정한다.
5. U006 APP_URL·U008 Auth Site URL/redirect·SNS/Toss callback·SEO/sitemap·메일 링크를 함께 갱신하고 재배포/검증한다.

## 검증·개발자 인계

최종 origin·소유권/TLS 상태·redirect 정책·변경한 관련 설정명·이메일/SNS/결제 callback 확인.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

DNS 전파/인증 문제 시 기존 검증된 도메인을 유지한다. 메일 레코드를 삭제하거나 HTTPS 확인을 우회하지 않는다.

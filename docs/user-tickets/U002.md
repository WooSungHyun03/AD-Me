## 사용자가 수행할 순서

1. GitHub에서 해당 저장소와 소유자를 확인하고 본인 계정 2FA·복구 수단을 설정한다. 토큰을 채팅으로 보내지 않는다.

3. Settings의 Rules/Branches에서 기본 브랜치 PR 검토·검증 CI 조건을 설정한다. 현재 플랜에서 지원하지 않는 보호 기능은 지원됨으로 표시하지 말고 수동 릴리스 검토로 대체한다.

5. PR/CI 권한은 최소화하고 외부 PR에 secret이 전달되지 않는지 확인한다. 기본 validation CI에는 배포 토큰이 필요하지 않다.

# U012 — Instagram 앱·OAuth·심사·키

담당: 사용자 · 우선순위: P2 · 현재 상태: USER_ACTION_REQUIRED · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

Meta 앱·계정 유형·승인 scope·개인정보 URL·철회 콜백·심사·키 발급/등록을 직접 진행한다.

## 시작 전에 개발자가 준비할 것

D022 구현·지원 Instagram Login/Facebook Login 방식·정확한 API 버전/scope·OAuth callback·삭제/철회 URL·심사 시연 자료.

## 사용자가 수행할 순서

1. Meta 개발자 포털에서 실제 목적에 맞는 앱·제품을 선택한다. Instagram 전문 계정 지원 범위와 선택한 로그인 방식 요건을 확인한다.
2. App 설정에 배포된 개인정보/이용약관/삭제·철회 URL과 구현된 OAuth redirect를 등록한다. 앱 소유자/필수 확인 정보를 사실대로 입력한다.
3. 개발·테스트 계정으로 최소 scope를 확인한다. Page 연결 요구는 로그인 방식에 따라 다르므로 무조건 Page가 필요하다고 설정하지 않는다.
4. 사용자 계정 밖 실제 사용에 필요한 심사/접근 수준/비즈니스 검증 여부를 확인한다. 사업자 미등록 상태로 충족할 수 없으면 기능을 P2 차단 상태로 둔다.
5. 현재 지원 앱 키·secret을 D003 계약에 따라 직접 등록하고 승인 scope·API 버전·만료/철회 흐름을 개발자와 검증한다.
6. 허용되지 않은 개인 계정 탐색이나 자동 DM 범위를 공개 기능으로 안내하지 않는다.

## 검증·개발자 인계

앱 ID·로그인 방식·버전·승인 scope·심사 상태·검증된 URL·연결/철회 결과. secret/token 제외.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

앱 심사나 사업 확인이 불가하면 YouTube/본인 등록 베타를 계속 운영한다. 다른 사람 앱/기업 명의로 우회하지 않는다.

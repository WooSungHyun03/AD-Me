# U013 — TikTok 앱·OAuth·심사·키

담당: 사용자 · 우선순위: P2 · 현재 상태: USER_ACTION_REQUIRED · 기준일: 2026-11-19

이 문서는 외부 작업의 실행 명세다. 문서 작성만으로 설정/승인/배포가 완료된 것은 아니다. 이전에 설정한 항목은 현재 상태를 확인해 증거를 남기면 재작업하지 않아도 된다.

## 목적·완료 조건

TikTok 앱·Display API scope·심사·콜백·키 발급/등록을 직접 진행한다.

## 시작 전에 개발자가 준비할 것

D023 구현·Login Kit/Display API 용도·scope·callback·권리/삭제 URL·샌드박스/심사 동영상.

## 사용자가 수행할 순서

1. TikTok for Developers에서 AD Me 앱을 등록하고 제품/소유자·웹 URL을 사실대로 입력한다.
2. Display API와 필요한 Login Kit, 최소 scope를 선택하고 현재 승인·조직/계정 자격 요건을 확인한다.
3. 배포된 약관/개인정보/삭제/redirect URL·허용 origin을 등록하고 테스트 사용자로 OAuth를 확인한다.
4. 기능별 설명·사용자 흐름·시연 자료로 심사를 신청한다. 승인 전에는 테스트 범위를 실제 전체 사용자 지원으로 표시하지 않는다.
5. 승인된 client key/secret과 scope를 D003/D023 계약에 따라 직접 등록한다. 연결→조회→갱신→철회→삭제를 검증한다.
6. Research API 접근은 별도 자격/목적이다. 상업 탐색 우회 허가로 간주하지 않는다.

## 검증·개발자 인계

앱 ID·승인 제품/scope·심사 결과·callback 확인·실제 동의 계정 연결/철회 결과. 비밀값 제외.

위 정보를 해당 개발 티켓 담당에게 전달한다. 성공 여부는 계정 화면의 설정과 실제 기능 검증을 함께 확인한다. 비밀값은 전달하지 않는다.

## 실패·중단·복구

승인/소유자 요건을 충족하지 못하면 비활성 유지하고 독립 베타 기능을 진행한다.

# 실제 데이터 파일럿 품질 게이트 (D024)

허용된 실제 YouTube 프로필 50~100개는 **목표**다. 이 폴더에는 실제로 확보해 검수를 통과한 수를 있는 그대로 기록한다.

## 실행 (운영자 또는 격리 DB)

```
node scripts/pilot-quality-report.mjs --env <env 파일> --out docs/evidence/data-pilot/<환경>-<YYYYMMDD>.json
```

- 서비스 롤 전용 RPC `public.pilot_quality_samples()`(마이그레이션 `20261126130000`, 조회수 숫자 판정은 `20261127100000`)를 읽는다.
- 서비스 롤 키는 출력하지도, 파일에 쓰지도 않는다.
- 종료 코드: `0` 목표 최소치 충족(MET), `3` 미충족(NOT_MET), `1` RPC 오류, `2` 설정 누락.

## 표본별 검사

| 항목           | 판정                                                                                                                                                                       |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 출처           | 채널 ID 형식(`UC…` 24자)이어야 원본 URL을 만들 수 있다                                                                                                                     |
| 수집 허용 근거 | `source`: U001이 `src/lib/ingestion/policy.ts`의 `youtube_data_api`를 승인했고 런타임 정책이 켜져 있다. `owner`: 확인과 동의를 마친 채널 소유자다. 둘 다 아니면 `no_basis` |
| 최신성         | 캐시 만료 또는 갱신 주기(30일) 초과면 `stale`                                                                                                                              |
| 결측           | 제목·구독자 수·영상·조회수                                                                                                                                                 |
| 중복           | 정규화한 제목 해시가 겹침                                                                                                                                                  |
| 삭제 대응      | 삭제 툼스톤이 있는데 행이 남아 있으면 `deleted_but_stored`                                                                                                                 |

- `ISOLATED…` 검토 참조를 가진 정책의 행은 QA 가상 데이터다. 파일럿 수에 절대 넣지 않고 `isolatedFixtures`로만 센다.
- 보고서에는 표본마다 불투명 참조(리소스 해시 앞 6바이트)만 남는다. 채널 ID·제목·소유자 정보는 남기지 않는다.

## 기록

| 파일                           | 환경                      | 결과                                                                                              |
| ------------------------------ | ------------------------- | ------------------------------------------------------------------------------------------------- |
| `local-isolated-20261126.json` | 로컬 격리 DB(가상 데이터) | 저장 10, 가상 데이터 10, 후보 0, 통과 0, NOT_MET. 공급원 미승인(U001). 실제 파일럿 증거가 아니다. |

실제 파일럿 결과는 U014(참가자·동의 확보)와 U001(공급원 승인) 뒤 운영자가 실행해 추가한다.

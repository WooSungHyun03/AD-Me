# D073/D080 실제 처리 흐름 대조 — 검토본

버전 beta-20261121-1 및 문서 해시는 src/lib/policy-document.json에 고정된다. 신규 정책은 기본 미승인이고 USER 검토 없이 public signup을 허용하지 않는다. 로컬 가상 QA 승인은 정식 승인·준법 완료가 아니다. 운영자/메일은 현재 공개 정책과 U001 부분 확인을 따르며 최종 보존·위탁/국외이전·권리 처리 절차는 미확정이다.

|---|---|---|

민감 특성·얼굴 인식/임베딩·건강/정치/종교/인종/성적 특성 추정은 지표 계약에서 배제한다. 공개 이름/소개의 분명한 주민번호·전화·이메일 패턴을 거부하고 전각 문자를 NFKC 정규화해 검사한다. 이는 모든 자유문장 개인정보를 찾는 완전한 분류기가 아니며 신고·운영 검토도 필요하다. 구조화 입력은 허용 필드를 고정한다. 생년월일·주민번호·신분증/실제 연령 검증을 새로 수집하지 않는다. 성인 확인은 만19세 이상 자기확인이다.

Supabase/Vercel과 선택적 Toss/LLM 제공자는 실제 계정 설정·계약·리전·하위 처리자·외부 전송을 USER가 확인해야 한다. 확인되지 않은 서울 리전·국외이전 부재·보존 기간을 확정 사실로 쓰지 않는다. 법적 검토 기준은 [개인정보 처리방침 제30조](https://www.law.go.kr/lsLinkCommonInfo.do?lsJoLnkSeq=1006185717), [파기·보존 제21조](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029334977). 최종 정책 반영은 개발자가 소스·snapshot/hash·SQL을 함께 준비하며 USER에게 코드 수정을 요구하지 않는다.

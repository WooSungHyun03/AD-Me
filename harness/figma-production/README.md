# Figma 전환 실행 Harness

원본 첨부의 86개 작업 정의와 검증기를 보존한다. 현재 사용 중인 실행 상태는 작업 폴더 `ADMe_Figma_Production_QA/state`에 있다. 초기 추가 발견 노드 4개와 출처는 `docs/design/figma-frame-map.json`에 기록했다. 중간 및 최종 티켓 상태의 공식 원장은 `docs/production-readiness/ALL_TICKETS.json`이다. 화면 적용 진행 상태 및 운영 잔여 게이트는 `docs/design/visual-review.md`, `docs/design/missing-frames.md`, `docs/production-readiness/GO_NO_GO.md`를 사용한다.

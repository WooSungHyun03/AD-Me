# D084 · 2026-11-25 keyless E2E regressions on main (new; earlier evidence unchanged)

Base: origin/main `b312ada`. Keyless build (`free_beta`, no keys) and isolated loopback replica `d002-replica` only. No hosted DB, deployment, payment or provider action.

## Reproduction (before)
`npm run test:e2e:keyless` failed 9 of 24 on unmodified main:
- `catalog-filters` ×6. The spec expects the 48-card fictional catalog, but the keyless config runs `free_beta`, which by design (D033, `7ec4cdd`) shows no fictional replacements. The spec was in the wrong config.
- `youtube-directory-unavailable` ×2. It asserted the pre-Figma heading "YouTube 크리에이터 탐색"; DEV-B's Figma directory redesign (`6a64ff7`) changed it.
- `free-mode` mobile ×1. On mobile the desktop "메인 메뉴" nav is hidden and the menu is "모바일 전체 메뉴", so the locator found nothing.

## Change
- `catalog-filters` moved to `tests/local-browser/` and runs against the DB cursor search (`test_demo` fictional catalog). It asserts the filtered total (`catalog-count`) plus visible cards (≤24 per page). Every filter assertion is kept.
- **Product fix (D034 UI):** an invalid range in the URL (e.g. `minPrice=500&maxPrice=0`) correctly skips the search, but the count stayed on "검색 결과를 확인하고 있습니다." forever. A range that became invalid after a search would also keep the old total. `catalog.tsx` now shows the empty result (0명) for invalid filters. The DB-path spec failed before the fix (desktop + mobile) and passes after it.
- D033 spec asserts the directory section heading "공개 YouTube 채널"; the free-mode spec asserts "AI 스튜디오" is absent from the whole banner (desktop + mobile menus).
- `serve-local-qa` proxies to the runtime's own API port instead of hard-coded 54321, so local QA cannot reach another checkout's stack.
- Replica hygiene: removed 2 fictional creators leaked by earlier p0-privacy runs (aborted cleanup, fixed in `07c7cd3`). They made totals 50, not 48.

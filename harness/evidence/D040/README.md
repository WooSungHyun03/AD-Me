# D040 — 개인 CRM 메모·후보 비교 리포트 (2026-11-22)

상태: 구현과 로컬 격리 DB 검증 완료. 호스트 적용(0019)은 사용자 `db push` 대기. 팀 메모는 팀 개념(DEV-A 계정/조직 모델)이 없어 **비공개(본인) 메모만** 구현했다.

## 구현
- `supabase/migrations/202611190019_notes_compare.sql`
  - `creator_notes`: 본인 전용 RLS(관리자도 API로 읽지 못함). 제안 `messages`와 다른 테이블·권한이다.
  - `compare_reports`: 2~3명, `share` 값은 private 또는 link. 링크 공유를 켜면 **서버가 토큰을 발급**한다(클라이언트가 고른 값은 무시). 끄면 토큰을 폐기하고, 다시 켜면 새 토큰을 만든다.
  - `shared_compare(token)`: anon도 호출할 수 있고 **제목과 크리에이터 ID만** 돌려준다. 작성자, 메모, 캠페인 정보는 없다.
- `src/lib/compare.ts`: 비교 항목을 하나로 정의한다(값과 결측을 따로 표시, "출처·근거"와 "기준 시점"은 별도 행). 실제 프로필에는 가상 수치를 표시하지 않는다. `compareCsv`는 ID와 `[결측]` 표기를 담고 메모는 넣지 않는다.
- API
  - `/api/notes PUT`: 2000자 이하, 빈 값이면 삭제.
  - `/api/compare`: POST(공개 프로필 2~3명만 저장), PATCH(공유 켜기/끄기), GET(ids 또는 share로 CSV, 공개 필드만).
- `/compare`: 값·결측 배지·출처·기준 시점 표, CSV(메모 제외), 본인 화면에만 "내 비공개 메모", 비교 저장(공유 범위 선택), 저장 목록(공유 링크와 공유 끄기). 공유 링크 화면에는 "메모·캠페인 정보 미포함" 안내만 나오고 메모 UI는 아예 렌더링하지 않는다.
- 개인정보 내보내기(D074)에 메모, 저장한 비교(토큰 제외), 동의 기록, 알림·마케팅·관심 분야·통계 제외 설정을 추가했다(D015/D006 데이터 누락 보완).

## 검증
- `tests/notes.mjs`(직접 REST):
  - 다른 계정·관리자·anon은 메모를 읽지도, 수정·삭제하지도 못한다. 남의 owner_id로 insert하면 거부된다. 빈 메모도 거부된다. messages에 메모 원문이 없다.
  - 비교는 1명이면 거부된다. 다른 계정·관리자·anon에게 행이 보이지 않고, 남의 이름으로 insert할 수 없다.
  - 토큰은 클라이언트가 지정해도 무시되고 update로도 바꿀 수 없다.
  - 공유 조회 결과는 정확히 `{title, creator_ids}`이고 작성자 id와 메모가 없다. 빈 토큰은 0건이다.
  - 공유를 끄면 기존 링크가 0건이 되고, 다시 켜면 새 토큰이 나온다.
- `tests/compare.test.ts`: ID 파싱(중복·수식·URL 제거, 최대 3명), 실제 프로필의 결측 5개 항목, CSV에 ID·결측 표기가 있고 메모 열이 없음.
- `tests/e2e/compare.spec.ts`(desktop+mobile):
  - 3명 비교와 결측 배지, 메모 저장 후 새로고침해도 유지, 링크 공유 저장.
  - **비로그인 사용자와 다른 계정**으로 링크를 열면 메모 원문과 메모 UI가 없고, CSV에도 메모가 없다.
  - 공유를 끄면 "공유가 꺼졌거나 없는 링크입니다"가 뜬다.
- 전체 회귀: 마이그레이션 19개, E2E 56/56, DB 테스트 17개, 복원 모의 PASS. vitest 107, lint/typecheck/build 0 오류, secret_scan --all PASS. 내보내기 변경 후 privacy.mjs와 privacy-export E2E를 다시 돌려 통과했다.
- 스크린샷: `compare-{desktop,mobile}.png`. 가로 스크롤 없음.
  - 첫 촬영은 로딩 화면이어서 대기 후 다시 찍었다.
  - 모바일 저장 목록 줄바꿈을 고쳤다.
  - E2E 메모 정리가 저장 완료 전에 끝나 남은 테스트 메모를 삭제했고, 이제 저장 완료까지 기다린다.

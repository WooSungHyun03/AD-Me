# D028 SNS 링크·임베드·공유

DEV-A · 기준 d1b2aa5 · 2026-11-19 KST

- D026의 외부 계정 소유 확인은 인계 대기다. 기존에 동의를 기록한 직접 등록 프로필의 링크 정규화와 공개 공유를 먼저 진행한다.
- 새 DB 필드는 없다. 새 SNS 링크와 기존 저장 링크가 같은 허용 규칙을 사용하며, YouTube 영상은 이용자가 요청한 시점에만 표준 iframe을 표시한다.
- 인가되지 않은 호스트·경로·프로토콜 거부, 공유의 공개 상태, 영상 원본 링크 및 브라우저 가드를 검증한다.
- Vitest 링크·공개 경로 계약 18개를 확인했다. 임베드 공급자의 재생 및 오류는 격리 브라우저 서버 E2E에서 확인할 항목이다. [YouTube 공식 도움말](https://support.google.com/youtube/answer/171780)

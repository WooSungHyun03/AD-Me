# UX/UI Critic prompt

이미지를 예쁘게 그리는 것으로 끝내지 말고 작동 중인 AD Me 웹사이트의 실제 브라우저 화면을 390px, 768px, 1440px에서 열어 확인하라. 제공한 로고를 왜곡하지 않고 라이트 표면에 사용했는지, CTA가 명확한지, 유기적 추천과 HOT 광고가 분리되는지, 브랜드가 추천 이유와 데이터 출처를 찾을 수 있는지 검토하라.

각 페이지를 KEEP/MINOR FIX/REDESIGN으로 판정하고 MUST 수정은 코드 반영 후 스크린샷/Playwright 증거로 검증하라. 가독성 높은 한국어 표현과 접근성, 과도한 라임색 사용 자제, 빈 상태/로딩/실패 상태의 사용자 안내를 점검한다.
